# again — 3 short-video scripts (vertical, 20–30s, screen-recording + VO)

Format notes: all shots are screen recordings (phone, vertical) unless noted. VO pace ~170 wpm. On-screen text in the app's plain lowercase style, big, centered-top. No music-drop gimmicks; a quiet steady track underneath.
